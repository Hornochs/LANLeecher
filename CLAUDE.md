# LANLeecher – notes for AI-assisted contributions

LANLeecher counts download and upload per client (MAC) for each LAN party event via SNMP and
serves rankings through a web UI and a REST API. Full design: `PROJECT_PLAN.md`.

**Everything in this repository is in English** – code, comments, docs, commit messages. The web UI
is bilingual; German strings live only in `internal/web/i18n.go`. The repository is public: never
commit credentials, internal hostnames, IP addresses or paths of a specific installation.

## Architecture

```
cmd/lanleecher/          CLI (cobra): server, config init, migrate, backup, user, event, switch, version
internal/accounting/     Pure delta and attribution logic – no I/O, table-driven tests
internal/collector/      IF-MIB polling (SNMP), interface classification (physical/LAG/virtual)
internal/fdb/            MAC → port (Q-BRIDGE, BRIDGE, Cisco community@vlan) and LLDP neighbors
internal/resolver/       IP/hostname: snmp-arp, local-neigh, netbios, mdns, llmnr, dns-ptr; merge suggestions
internal/scheduler/      One poll loop per switch; books deltas into the active event
internal/store/          SQLite (modernc, no CGO), goose migrations in migrations/sqlite/
internal/board/          Beamer data; /board and /api/v1/board deliver exactly the same
internal/api/            REST v1; openapi.yaml is the single source of truth (a test checks routes ↔ spec)
internal/web/            html/template + htmx, embedded assets, i18n (en/de) in i18n.go
internal/auth/           Argon2id, tokens (llk_…), login lockout, rate limit
packaging/               Package config, systemd unit, sysusers, install scripts, install test
tools/gendocs/           Generates docs/configuration.md, docs/config.schema.json, docs/llms-full.txt
docs/, examples/         User docs, ADRs, API guide; runnable API examples
```

## Rules that must not be broken

- **Direction:** `ifHCInOctets` is the client's *upload*, `ifHCOutOctets` its *download*.
  The mapping exists only in `accounting.ClientDirection`.
- **Store deltas only.** Totals are sums of deltas; a counter reset on a switch must never reduce a total.
- **Uplinks** are counted on the port only, never attributed to a MAC.
- **Hiding** is filtered at query time (join on `ports`/`devices`), never written into totals.
- **Credentials** (communities, v3 passwords) are stored AES-GCM encrypted in the database only – never
  in logs, the audit log, API responses or pre-filled forms.
- Hostnames and `ifAlias` come from the network: always escape, no inline JS/CSS (CSP).
- No change to API, config or data model without matching docs (`openapi.yaml`, `docs/`, `PROJECT_PLAN.md`).
  Configuration docs and `docs/llms-full.txt` are generated: run `go run ./tools/gendocs` (a test checks it).

## Commands

```bash
go vet ./...
go test ./...                              # the integration test needs snmpsim (see below), otherwise it is skipped
go test -short ./...                       # without integration tests
CGO_ENABLED=0 go build -o bin/lanleecher ./cmd/lanleecher
./bin/lanleecher -c config.yaml config init && ./bin/lanleecher -c config.yaml server
```

If your installed Go is newer than needed, set `GOTOOLCHAIN=local` so that `go get` does not pull
module versions that require a newer toolchain.

snmpsim for the integration tests: `python3 -m venv .venv && .venv/bin/pip install snmpsim pysmi`
(or `LANLEECHER_SNMPSIM=/path/to/snmpsim-command-responder`). Fixture:
`testdata/snmpsim/testswitch.snmprec`, generated by `testdata/snmpsim/gen.py`.

## Releases

Create and publish a release with tag `vX.Y.Z` in the GitHub web UI (write the notes there).
`.github/workflows/release.yml` then builds with GoReleaser (`.goreleaser.yaml`): binaries and
archives for linux amd64/arm64/armv7, `.deb`, `.rpm`, `.pkg.tar.zst` and `.apk` packages,
`SHA256SUMS` and the multi-arch image `ghcr.io/<owner>/lanleecher`. Every amd64 package is first
installed, started and removed in a fresh container (`packaging/test-install.sh`); only then are the
files attached, the images pushed and the build provenance attested. The build is reproducible
(`-trimpath`, commit timestamps), so the published files are bit-identical to the tested ones.

Check locally: `goreleaser check` and `goreleaser release --snapshot --clean --skip=publish,docker`.

## Conventions

- Go 1.24; no dependency that requires a newer toolchain.
- Logging with `log/slog`; wrap errors with context (`fmt.Errorf("…: %w", err)`).
- Timestamps in the database as Unix seconds (UTC), bytes as 64-bit integers.
- UI texts only via keys in `internal/web/i18n.go` (English and German).
- Never change a migration once it is released – add a new file.
- Commit messages in English, imperative mood.
