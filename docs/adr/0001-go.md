# 0001 – Go instead of Python

**Status:** accepted

## Context

LANLeecher polls many switches concurrently, does little CPU work per poll, and should be trivial to
install on a Raspberry Pi at a LAN party – possibly without internet access. Sibling projects use
Python (LANPilot) and Go (FlowGauge).

## Decision

LANLeecher is written in Go. SNMP uses `gosnmp`, SQLite the pure-Go `modernc.org/sqlite`, so the
binary is built with `CGO_ENABLED=0`.

## Consequences

- One static binary per architecture; packages contain no runtime or virtual environment.
- One goroutine per switch is cheap; no async framework needed.
- Templates, static assets, migrations and the OpenAPI document are embedded in the binary.
- Contributors need Go instead of Python. Test tooling (snmpsim) still uses Python, outside the binary.
